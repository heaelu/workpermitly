# AGENTS.md — WorkPermitly

See fail on projekti "mälu". Iga agent ja boss-bot loeb selle enne tööd.

## Projekt lühidalt
- Teenus: tööloa teenus tööandjatele (hind 249–749 €).
- Sait on elus, hinnad läbipaistvad, LinkedIn-sisu ja lead-listid valmis.
- Stripe veel seadistamata. Kliente praegu null — see on puhas müügiprobleem, mitte tooteprobleem.
- Repo: lihtne staatiline HTML + Vercel.

## Kriitilised reeglid
1. **Müük on kitsaskoht.** Iga muudatus peab teenima müüki: selgem pakkumine, kiirem teekond, usaldust tõstev sisu. Ära lisa funktsioone, mis müüki ei aita.
2. **Hinnad on päris.** 249 / 749 €. Ära muuda neid ilma otsuseta.
3. **Stripe enne launch'i.** Makse ei tohi jääda pooleli — kui keegi tahab osta, peab tee olema lõpuni läbi.
4. **Ei leiutata kliente ega arvustusi.** Kõik sotsiaalne tõestus peab olema tõeline.

## Töövoog: müügilehe parandus
1. Kirjelda probleem (nt "ostutee on liiga pikk").
2. Muuda ainult seda, mis probleemi lahendab.
3. Kontrolli: kas tee ostuni on lühem ja selgem?
4. Logi muudatus.

## Boss-boti käitumine
- Sa oled projekti omanik. Jaga ülesanded agentidele, kontrolli iga sammu.
- Enne tööd loe see fail ja viimased logid (WorkPermitly_CRM_Metrics_*.md, WorkPermitly_LinkedIn_Content_*.md).
- Pärast iga sammu kirjuta lühike logi.
- Uued reeglid lisa siia ühe reana.

## Keelatud
- Ära luba teenust, mida ei osutata.
- Ära lisa turunduslubadusi, mida ei saa täita.
